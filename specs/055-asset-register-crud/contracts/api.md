# API Contracts: Asset Register CRUD

**Feature**: 055-asset-register-crud | **Date**: 2026-09-15

## Endpoint Group: `/api/Assets`

| Verb | Route | Handler | Permission | Produces |
|------|-------|---------|------------|----------|
| GET | `/api/Assets` | HandleGetAll | Assets.View | PaginatedList<AssetResponse> |
| GET | `/api/Assets/{id}` | HandleGetById | Assets.View | AssetDetailResponse |
| POST | `/api/Assets` | HandleCreate | Assets.Create | int (new ID) |
| PUT | `/api/Assets/{id}` | HandleUpdate | Assets.Update | Result |
| POST | `/api/Assets/{id}/deactivate` | HandleDeactivate | Assets.Update | Result |

**Request Body**:

```json
  "description": "طابعة ليزر أسود وأبيض",
  "assetGroupId": 2,

  "fundId": 1,
  "costCenterId": 3,
  "custodianId": 42,
  "assetTag": "TAG-HP-001",
  "barcode": "1234567890123",
  "serialNumber": "HP-SN-2025-001",
  "currencyCode": "SAR",
  "originalValue": 1500.00,
  "acquisitionCost": 100.00,
  "residualValue": 150.00,
  "purchaseDate": "2025-01-15",
  "depreciationStartDate": "2025-02-01",
  "acquisitionType": "Purchase",
  "usefulLifeYears": 5,
  "notes": "تم الاستلام من المورد المعتمد"
}
```

**Notes**:
- `code` is NOT in request body — auto-generated by DocumentSequenceService
- `status` is NOT in request body — defaults to "Draft"
- `currentValue` defaults to `originalValue`
- `accumulatedDepreciation` defaults to 0

**Response 201**: `1` (new asset ID)

**Response 400**: Validation errors

```json
{
  "errors": {
    "Name": ["اسم الأصل مطلوب"],
    "AssetGroupId": ["المجموعة مطلوبة"],
    "OriginalValue": ["القيمة الأصلية مطلوبة"],
    "Barcode": ["الباركود مستخدم بالفعل"]
  }
}
```

```json
  "residualValue": 150.00,
  "purchaseDate": "2025-01-15",
  "depreciationStartDate": "2025-02-01",
  "acquisitionType": "Purchase",
  "usefulLifeYears": 5,
  "notes": "تم التحديث",
  "rowVersion": "AAAAAA=="
}
```

**Notes**:
- `rowVersion` is REQUIRED for optimistic concurrency
- When status is Active+: `originalValue`, `purchaseDate`, `assetGroupId` are rejected (field locked)

**Response 200**: `Result.Success()`

**Response 400**: Validation/concurrency errors

**Response 409**: `{ "error": { "code": "ConcurrencyConflict", "message": "..." } }`

## Error Response Contract

All error responses follow the problem-details format:

```json
{
  "type": "about:blank",
  "title": "Bad Request",
  "status": 400,
  "errors": {
    "FieldName": ["Error message in Arabic"]
  }
}
```

Error codes are machine-readable; messages are user-friendly Arabic text.
