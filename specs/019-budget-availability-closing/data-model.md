# Data Model: Financial Control Layer

**Feature**: 019-budget-availability-closing | **Date**: 2026-09-05

## New Entities

### YearClosingRun

Append-only record of a fiscal year closing or reopening operation.

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| Id | int | PK, Identity | |
| FiscalYearId | int | FK → FiscalYear, NOT NULL | |
| RunAt | DateTimeOffset | NOT NULL | Timestamp of the run |
| RunById | int | FK → User, NOT NULL | Actor who initiated |
| RunType | enum | NOT NULL | Lapse, Reopen |
| LapsedAppropriationTotal | decimal(23,2) | NOT NULL, default 0 | Total appropriation amount lapsed |
| LapsedEncumbranceTotal | decimal(23,2) | NOT NULL, default 0 | Total encumbrance amount lapsed |
| Status | enum | NOT NULL | Completed, Reversed |
| ReversedById | int? | FK → User, nullable | Set when Status = Reversed |
| ReversedAt | DateTimeOffset? | nullable | Set when Status = Reversed |
| RowVersion | byte[] | concurrency token | |

**Relationships**:
- Belongs to FiscalYear (many-to-one)
- Created by User (RunById)
- Reversed by User (ReversedById, nullable)

**Constraints**:
- Unique index on (FiscalYearId) WHERE Status = Completed — prevents duplicate active lapses
- Append-only: UPDATE and DELETE are prohibited at the application level

### FinalAccount

The authoritative financial statement for a closed fiscal year.

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| Id | int | PK, Identity | |
| FiscalYearId | int | FK → FiscalYear, UNIQUE, NOT NULL | One final account per year |
| GeneratedAt | DateTimeOffset | NOT NULL | |
| GeneratedById | int | FK → User, NOT NULL | |
| Status | enum | NOT NULL | Draft, Issued |
| IssuedAt | DateTimeOffset? | nullable | Set on approval |
| IssuedById | int? | FK → User, nullable | Set on approval |
| RowVersion | byte[] | concurrency token | |

**Relationships**:
- Belongs to FiscalYear (one-to-one via unique index)
- Contains FinalAccountLines (one-to-many)
- Generated by User (GeneratedById)
- Issued by User (IssuedById, nullable)

**State transitions**:
- Draft → Issued (on approval, immutable after this)

### FinalAccountLine

A line item in the final account — materialized at generation time.

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| Id | int | PK, Identity | |
| FinalAccountId | int | FK → FinalAccount, NOT NULL | |
| Dimension | enum | NOT NULL | Fund, Program, Project, Item |
| DimensionId | int | NOT NULL | FK value for the dimension entity |
| DimensionCode | string | NOT NULL | Denormalized code for display |
| DimensionName | string | NOT NULL | Denormalized name for display |
| BudgetedAmount | decimal(23,2) | NOT NULL | Appropriation amount for this dimension |
| ActualAmount | decimal(23,2) | NOT NULL | Executed payment amount for this dimension |
| Variance | decimal(23,2) | NOT NULL | BudgetedAmount - ActualAmount |
| RowVersion | byte[] | concurrency token | |

**Relationships**:
- Belongs to FinalAccount (many-to-one)

**Constraints**:
- Unique index on (FinalAccountId, Dimension, DimensionId) — one line per dimension value per final account

## Extended Entities

New method added to `IBudgetAvailabilityService`:

```csharp
Task<List<AvailabilityBreakdownDto>> GetAvailabilityBreakdownAsync(
    int budgetItemId, int fiscalYearId);
```

## Migration Notes

1. **Three new tables**: YearClosingRun, FinalAccount, FinalAccountLine
2. **No schema changes** to existing tables (Appropriation, Encumbrance, FiscalYear)
3. **Seed data**: Permission codes for FinancialControl.LapseYear and FinancialControl.ApproveFinalAccount
4. **Indexes**: Unique index on YearClosingRun(FiscalYearId) WHERE Status = Completed; unique index on FinalAccount(FiscalYearId); unique index on FinalAccountLine(FinalAccountId, Dimension, DimensionId)
